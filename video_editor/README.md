# PyVideoEditor - 本地视频剪辑软件

一个基于 PySide6 的自用视频剪辑软件，类似"剪映"的基础功能。

## 项目结构

```
video_editor/
├── main.py                 # 主程序入口
├── core/                   # 核心模块
│   ├── __init__.py
│   ├── config.py          # 配置和常量
│   ├── models.py          # 数据模型（片段、轨道、时间轴、项目）
│   └── engine.py          # 媒体处理引擎（ffmpeg 集成）
├── ui/                     # 用户界面模块
│   ├── __init__.py
│   ├── main_window.py     # 主窗口
│   ├── preview_widget.py  # 预览窗口组件
│   ├── timeline_widget.py # 时间轴组件
│   ├── media_library.py   # 素材库组件
│   ├── properties_panel.py # 属性面板组件
│   └── toolbar_widget.py  # 工具栏组件
├── utils/                  # 工具函数模块
│   └── __init__.py
└── resources/              # 资源文件
    └── icons/             # 图标文件
```

## 功能特性（第一阶段）

### 已实现的基础功能

1. **视频编辑**
   - 导入视频文件
   - 多轨道视频编辑
   - 视频片段拖拽到时间轴
   - 片段移动和调整

2. **音频处理**
   - 导入音频文件
   - 独立音频轨道
   - 音量调节
   - 淡入淡出效果

3. **字幕功能**
   - 添加文字字幕
   - 自定义字体、大小、颜色
   - 背景色和透明度
   - 位置调整

4. **画中画/素材叠加**
   - 图片叠加
   - 位置、缩放、旋转调整
   - 透明度控制

5. **时间轴编辑**
   - 多轨道显示
   - 播放头拖动
   - 时间标尺
   - 缩放控制
   - 片段选择、删除

6. **预览播放**
   - 视频预览窗口
   - 播放/暂停控制
   - 逐帧预览
   - 进度跳转
   - 播放速度控制

7. **素材库管理**
   - 媒体文件导入
   - 缩略图显示
   - 搜索和筛选
   - 拖拽添加

8. **属性编辑**
   - 选中片段属性查看
   - 实时属性修改
   - 颜色选择器

## 安装依赖

```bash
pip install pyside6
```

可选（用于视频处理）：
```bash
# 需要安装 ffmpeg
# Ubuntu/Debian:
sudo apt install ffmpeg

# macOS:
brew install ffmpeg

# Windows: 从 https://ffmpeg.org/download.html 下载
```

## 运行程序

```bash
cd video_editor
python main.py
```

## 使用说明

### 基本操作流程

1. **新建项目**: 启动后自动创建新项目
2. **导入素材**: 点击"素材库"中的"➕ 导入"按钮，或菜单"文件 > 导入媒体"
3. **添加到时间轴**: 双击素材或拖拽到时间轴区域
4. **编辑片段**: 
   - 拖动片段调整位置
   - 在属性面板修改参数
5. **播放预览**: 点击预览窗口的播放按钮或按空格键
6. **导出视频**: 菜单"文件 > 导出视频"

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Space | 播放/暂停 |
| Ctrl+Space | 停止 |
| Home | 跳到开头 |
| End | 跳到结尾 |
| Ctrl+K | 分割片段 |
| Delete | 删除选中 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+E | 导出视频 |
| Ctrl+S | 保存项目 |
| Ctrl+O | 打开项目 |
| Ctrl+N | 新建项目 |

### 鼠标操作

- **左键拖动播放头**: 在时间轴标尺上左右拖动
- **左键拖动片段**: 移动片段位置
- **滚轮**: 垂直滚动时间轴
- **Ctrl+ 滚轮**: 缩放时间轴
- **右键菜单**: 显示上下文操作菜单

## 技术架构

### MVC 模式

- **Model (模型)**: `core/models.py` - 数据结构定义
- **View (视图)**: `ui/` - 所有 UI 组件
- **Controller (控制器)**: `core/engine.py` - 业务逻辑

### 信号槽机制

使用 Qt 的信号槽机制实现组件间通信：
- 素材库 → 主窗口：媒体导入完成
- 时间轴 → 主窗口：时间变化、选择变化
- 预览窗口 → 主窗口：播放状态变化

### 线程模型

当前版本在主线程运行所有操作。
后续优化建议：
- 媒体加载使用 QThread
- 渲染使用单独线程
- 文件 I/O 异步处理
